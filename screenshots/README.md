# Screenshot capture guide

This directory stores public screenshots for release pages and a future Moodle Marketplace listing. Capture images only from a disposable demonstration course with fictional users and no personal, institutional, or production data.

## Required screenshots

1. A shared board with distinct columns and example cards.
2. The group-board configuration selector with selected and available groups.
3. The group-board selector showing the active group board.
4. A template or board action that demonstrates structural replication.
5. An imported destination activity showing custom columns and no imported cards.

## Capture requirements

Use a current supported Moodle version, desktop viewport, and the default Moodle theme where possible. Remove browser chrome, course navigation that exposes real users, session data, and debugging output.

Use PNG files. Name each image by the behaviour it demonstrates, for example shared-board.png or group-selection.png. A screenshot must match the release being published. Replace it when the relevant interface changes.
