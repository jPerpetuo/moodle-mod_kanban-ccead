# Kanban 0.4.0-beta

Version 0.4.0-beta prepares this derivative of mod_kanban for broader Moodle compatibility and operational use. It keeps the mod_kanban component identity and replaces the original plugin in place.

## Compatibility

The declared supported range is Moodle 4.1 through Moodle 5.2. The release requires JavaScript.

## Board configuration

* Activities support shared boards, selected group boards, and optional personal boards.
* Group-board configuration requires at least one selected group. When a course has no groups, the form directs the teacher to create groups or choose a shared board.
* The group selector follows Moodle's dual-list interaction and explains how to add and remove selected groups.
* Users without an all-boards capability cannot obtain another group board by changing a board identifier in the URL.

## Cards and templates

* Student card movement is validated in the activity user interface.
* Cards created in a completion column are completed, and completing a card moves it to the configured completion column when available.
* Templates and board replication copy board structure only. They retain column titles, order, colours, options, and locks, but do not copy cards or card content.
* Applying a template to a board containing cards requires explicit confirmation.

## Backup, restore, and course import

Course import without user data preserves activity settings and board structure. Custom columns, colours, options, order, and locks are restored without cards, attachments, assignees, discussions, history, or other prior-course user content.

Selected group boards are retained only when Moodle imports groups. Source-group identifiers and source users are not retained in the destination course.

## Upgrade notes

Install this release as a replacement for an existing mod/kanban directory. Do not install it alongside another mod_kanban distribution.

Before production deployment, back up the Moodle database, moodledata, and current plugin directory. Run Moodle's upgrade process, purge caches, and validate the activity flows described in [Release and operations](../release.md).

## Beta status

This is a beta release. Validate shared boards, group boards, role access, templates, and course import in a staging Moodle site before production deployment.
