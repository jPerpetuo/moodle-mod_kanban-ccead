# Security policy

## Supported releases

Security fixes are evaluated for the current supported plugin release and its declared Moodle compatibility range in [version.php](version.php). The repository does not guarantee fixes for obsolete releases.

## Reporting a vulnerability

Do not report suspected vulnerabilities in a public issue. Do not include credentials, session keys, personal data, or exploit details in public channels.

When this repository is public and GitHub private vulnerability reporting is enabled, use the repository's private vulnerability-reporting channel. GitHub provides repository security advisories and private vulnerability reporting for public repositories.

Until that channel is available, contact a repository maintainer through a private contact method they provide. Include the affected plugin and Moodle versions, a minimal reproduction, impact, and any proposed mitigation.

## Disclosure

Maintainers will assess the report, prepare and validate a fix when appropriate, and publish an advisory after a fix or mitigation is available. Reports may be declined when they do not affect this plugin or cannot be reproduced.
